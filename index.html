How to read this report

Total productivity time is talk time + wrap time + total ring time. Talk and wrap time come from Ozonetel call records when available, with the state summary used for completed dates. Break time uses the same detailed history as the Agent Break Dashboard: completed breaks plus today’s ongoing breaks, excluding SIP disconnections and mode changes. Average ring time before agent cuts is total customer ring time divided by recorded calls, including calls with zero ring time. The overall average is weighted by call count.

!

A note on idle time

“System Error” is your requested label. The value is Ozonetel’s reported idle time; it does not independently verify a system fault.
